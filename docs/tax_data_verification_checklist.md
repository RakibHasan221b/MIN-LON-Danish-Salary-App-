This is a companion to `docs/research_2026.md` (which has the full narrative for each item) — this file is the flat, scannable table the task asked for. "Verified" means checked against an official or near-official source (skat.dk, bm.dk, svmn.dk/skm.dk, Danmarks Statistik, borger.dk/virk.dk); "corroborated" means a third-party source was cross-checked against an official aggregate figure but not confirmed row-by-row; "assumption" means no source was found either way and the app documents its own choice; "not verified" means genuinely open and flagged for follow-up.

## How to use this table

- "Verified" and "Corroborated" rows need no action before relying on the app for illustrative estimates.
- Every row marked "Not verified" or "Assumption" is also called out in `docs/research_2026.md` and, where it affects the calculation directly (ATP-by-age, AM-bidrag age exemption, Frikort balance base), in the app's own `assumptions` list returned with each result — the app never claims more certainty than this table supports.
- This file should be updated whenever a new tax year's data is added, or whenever one of the open items above gets independently verified.
